# Natural Pigment Lab

A static/offline-friendly educational web app inspired by **Lucy Mayes, _The Natural Pigment Handbook_**.

## Run locally

No build step is required for the simplest test:

1. Open `index.html` in a modern browser.

For GitHub + Vite development:

```bash
npm install
npm run dev
```

For production:

```bash
npm run build
```

## Included

- Pigment Library
- History timeline
- Recipe Lab with step-by-step navigation
- Chemistry cards
- Ingredient / equipment glossary
- Safety notes
- Pigment comparison
- Personal Pigment Journal using localStorage
- Search and category filters
- Responsive desktop/mobile interface

## Source note

The app uses the uploaded book as its primary study source. The application content is structured and rewritten for an interactive learning interface rather than presenting the book as a page-by-page reproduction. Recipe quantities and process notes are attributed to the source within the app where used.

## Important

This is an educational artist-materials tool, not a chemical laboratory manual. Some pigment processes involve heat, alkalinity, acids, metal salts, copper compounds, dust, or combustion. Use appropriate PPE, ventilation, non-food equipment, and local hazardous-material guidance.
